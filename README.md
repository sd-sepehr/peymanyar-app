# پیمان‌یار

فایل برنامه پیمان‌یار: تحلیل، تنظیم و پیگیری قراردادها، کاملاً در مرورگر و بدون اینترنت.

- دانلود: [peymanyar.html](peymanyar.html)، یا صفحه دانلود همین مخزن در GitHub Pages
- یک فایل HTML است؛ با Chrome یا Edge باز کنید. به اینترنت نیاز ندارد و داده‌ها فقط در همان مرورگر می‌مانند.
- این مخزن فقط فایل ساخته‌شده برنامه را دارد؛ کد منبع اینجا نیست.

کتابخانه‌ها و مدل‌های داخل فایل (متن مجوز هر کدام داخل خود فایل آمده است):
- pdf.js و mammoth.js
- tesseract.js
- onnxruntime-web (MIT) و مدل PP-OCRv5 (Apache-2.0)
- فونت‌های Vazirmatn و Noto Naskh Arabic (SIL OFL 1.1)
